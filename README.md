# Hostel Expense & Budget Tracker

## Overview of the Project
A modular Python application built to help university students track their monthly pocket money and prevent overspending.

## Features
- Add daily expenses with custom descriptions.
- View a running list of all recorded expenses.
- Check remaining balance instantly.
- Automatic alert triggers when the balance drops below 20%.

## Technologies/Tools Used
- Python 3
- Core Logic (While loops, lists, dictionaries, if/else conditions)

## Steps to Install & Run the Project
1. Download or clone this repository to your local machine.
2. Open your terminal or command prompt.
3. Navigate to the project folder.
4. Run the command: `python file5_main.py`

## Instructions for Testing
Run the command `python file6_test_tracker.py` to execute the built-in unit tests that validate the core arithmetic and analytics logic.
